Κλασικά παραδείγματα είναι η αναγνώριση εικόνων/βίντεο, η επεξεργασία φυσικής γλώσσας (NLP) και η αναγνώριση ομιλίας. Αντίθετα, για απλά προβλήματα με δομημένα δεδομένα, τα παραδοσιακά μοντέλα Μηχανικής Μάθησης είναι προτιμότερα καθώς είναι πολύ πιο γρήγορα και απαιτούν λιγότερους πόρους.

d. Η Βαθιά Μάθηση μπορεί να χρησιμοποιηθεί και στους 3 κλάδους της Μηχανικής Μάθησης;

Supervised Learning (Επιβλεπόμενη Μάθηση): Όπως κάναμε σε αυτή την εργασία, όπου δίνουμε στο δίκτυο εικόνες και τις αντίστοιχες σωστές ετικέτες (0-9) για να εκπαιδευτεί.

Unsupervised Learning (Μη Επιβλεπόμενη Μάθηση): Χρησιμοποιώντας αρχιτεκτονικές όπως Autoencoders (για μείωση διαστάσεων) όπου το δίκτυο βρίσκει μόνο του μοτίβα χωρίς έτοιμες ετικέτες.

Reinforcement Learning (Ενισχυτική Μάθηση): Τα Deep Q-Networks χρησιμοποιούνται ευρέως για την εκπαίδευση πρακτόρων (agents) μέσω επιβράβευσης/τιμωρίας (π.χ. εκπαίδευση συστημάτων τεχνητής νοημοσύνης σε πολύπλοκα βιντεοπαιχνίδια ή στη ρομποτική).

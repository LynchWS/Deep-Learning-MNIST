**Workflow & Architecture:**
Η ροή εργασίας (workflow) περιελάμβανε τη φόρτωση και κανονικοποίηση του dataset της MNIST (reshape σε 784, /255.0), την one-hot κωδικοποίηση των ετικετών και την εκπαίδευση πολλαπλών αρχιτεκτονικών. Η τελική επιλεγμένη αρχιτεκτονική του μοντέλου αποτελείται από:
* Input Layer (784)
* Hidden Layer 1: 256 neurons (tanh) + Dropout(0.3)
* Hidden Layer 2: 256 neurons (tanh) + Dropout(0.2)
* Output Layer: 10 neurons (softmax)
* Optimizer: SGD (learning_rate=0.001)
* Loss: categorical_crossentropy
